Version 2.15.0. Adding a device: new two-step flow (Plug or Smoke detector), with an automatic probe on a plug's IP address — its already-configured name is picked up as-is if it has one, no need to retype it. For a smoke detector, the screen now walks you through waking it up manually (3 short presses) before confirming, so its real name can be read instead of overwriting the device with placeholder text. Automatic firmware check: once a day at launch, for devices with Shelly Cloud enabled, an "Update available" banner appears on the affected tile; tapping it opens the update screen directly. Fixed: the red "no relay available" banner could wrongly appear even when a relay was working fine; an Active tile with a cutoff threshold no longer sits at a different height than an Unavailable tile next to it in the grid.
